========================================================
 HUONG DAN SU DUNG: THANH NGAY & GIO TIKTOK LIVE STUDIO
========================================================

1. NOI DUNG THU MUC:
   - `tiktok-clock-overlay.html`: Giao diện đồng hồ chính (kèm tuỳ chỉnh theme, bo góc, phông xanh).
   - `Cai_Dat_Tu_Khoi_Dong.bat`: Script tự động đưa đồng hồ vào khởi động cùng Windows (Startup).
   - `Go_Bo_Tu_Khoi_Dong.bat`: Script gỡ bỏ khởi động cùng Windows khi không dùng nữa.

2. CACH GAN LEN TIKTOK LIVE STUDIO (KHUYEN DUNG):
   - Mo TikTok Live Studio.
   - Them nguon moi: Chon **Browser Source (Liên kết)**.
   - Dan duong dan hoac chon file `tiktok-clock-overlay.html` vua giai nen.
   - Nhan phim **F9** tren ban phim de an bang dieu khien, giu lai rieng thanh dong ho trong suot 100% vo cung chuyen nghiep!

3. TU KHOI DONG CUNG WINDOWS:
   - Nhay dup vao file `Cai_Dat_Tu_Khoi_Dong.bat` de kich hoat tinh nang tu mo khi bat may.
